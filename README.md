# 옛날바람(메이플스토리 월드) 주술사 매크로

macOS에서 옛날바람 주술사로 굴(흉가, 비밀세작의집)을 돌며 자동으로 사냥하는 매크로입니다.
화면을 읽어 체력/마력, 좌표, 맵 이름, 대상 선택 상자를 알아내고 키 입력을 보냅니다.

- 방을 차례로 지나가며 사냥하고, 한 바퀴가 끝나면 다시 들어가 계속 돕니다.
- 싸울 때는 자신에게 대상을 고정해 힐과 공격 스킬을 번갈아 쓰고, 쿨이 돌 때마다 헬파이어를 씁니다.
- 싸운 자리의 상하좌우 칸을 살펴보기 키로 확인해 아이템이 있는 칸만 밟아 줍습니다.
- 죽으면 성황당에서 되살아나 사냥터로 돌아갑니다.

제2상곡흉가 기준으로 한 바퀴 약 29분, 분당 경험치 약 670만입니다 (2026-10-11 측정, 146분).

## 준비

macOS 전용입니다. 게임 창 크기 1920x1050 기준으로 좌표가 맞춰져 있습니다.

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

터미널(또는 실행하는 앱)에 **손쉬운 사용**과 **화면 기록** 권한을 줘야 합니다.

## 게임 키 세팅

`config.toml`의 `[keys]`와 게임 안 단축키가 같아야 합니다. 기본값은 다음과 같습니다.

| 키 | 스킬 |
|---|---|
| 1, 3 | 공격 스킬 |
| 2 | 힐 (타겟팅을 나에게로) |
| 4 | 저주 |
| 5 | 공력증강 |
| 6, 7 | 보호, 무장 |
| 9 | 헬파이어 |
| Space | 기본 공격 |
| Ctrl+Z | 마나물약 |
| Shift+, | 아이템 줍기 |
| ; | 살펴보기 |
| Shift+Z → L | 성황령 (부활) |
| Shift+Z → K | 비영사천문 |

## 사용

게임 창을 화면에 띄워 둔 채로 실행합니다.

```sh
./start.sh     # 지금 서 있는 맵을 알아내 제2상곡흉가 사냥을 시작
./stop.sh      # 끄기
./watch.sh     # 약 10분 지켜보다 꺼져 있으면 다시 켜고, 끝에 요약을 찍음
```

- **바로 끄기**: 게임 창이 맨 앞일 때 `F7`. F7로 끈 경우 `watch.sh`는 다시 켜지 않습니다.
- `start.sh`는 흉가 방, 흉가입구, 성에서 시작할 수 있습니다. 방 안이면 그 흉가를, 성이나 입구면 그 성의 제2 흉가를 돕니다. 기록은 `logs/`에 남습니다.
- `PICK=1 ./start.sh`: 성이나 흉가입구에서 켤 때, `/출 흉가`로 사람이 없는 흉가를 골라 입구 앞에 노란비서를 버리고 들어갑니다.

### 사냥하면서 스스로 하는 일

- **호박 팔기**: 10번 방을 나올 때마다 가방을 보고 호박이 100개면 부여장터에 가서 팝니다 (부여성비서 → 장터 → "호박 다 판다", "진호박 다 판다" → 세계지도로 복귀, 약 1분 반).
- **빈 흉가 고르기**: 팔고 돌아오면 `/출 흉가`를 쳐서 사람이 있는 흉가를 읽고, 제2가 비었으면 제2, 아니면 빈 다른 흉가로 갑니다. 그 성이 꽉 찼으면 `haunt_castles`에 적힌 다음 성으로 갑니다.
- **미니게임**: 1초마다 화면을 보다가 "같은 몬스터 위에 놓기" 창이 뜨면 매크로를 세우고 한 번 풀어 본 뒤 다시 움직입니다 (`minigame_daemon.py`).
- **기록**: 방을 나올 때마다 걸린 시간과 오른 경험치를, 10번 방을 나올 때 한 바퀴 시간과 분당 경험치를 로그에 찍습니다.

직접 실행할 수도 있습니다.

```sh
.venv/bin/python hunt.py 지금있는맵이름 --haunt=제2상곡흉가 --overnight
.venv/bin/python nav.py 지금맵이름 목표맵이름      # 여러 맵을 거쳐 걸어가기
.venv/bin/python record.py 지금있는방이름          # 직접 걸은 길을 기록
.venv/bin/python wind.py check                     # 체력/마력 인식값 확인
```

`--overnight`은 사람이 없는 동안 돌릴 때 씁니다. 게임 창을 스스로 앞으로 가져오고, 40분마다 방 경계에서 프로세스를 새로 띄웁니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `hunt.py` | 방을 돌며 사냥, 줍기, 부활 |
| `wind.py` | 화면 읽기, 키 입력, 대상 선택창 처리 |
| `nav.py` | 좌표를 읽어 길 찾기, 맵 사이 이동 |
| `grabber.py` | 화면 캡처 전용 일꾼 프로세스 |
| `record.py` | 걸은 길과 출구 기록 (번호 붙은 방) |
| `record_route.py` | 걸은 길, 누른 키, 화면을 보기만 하며 기록 (성 → 장터 같은 길) |
| `market.py` | 부여장터에 가서 호박 팔고 오기, 가방에서 "호박 100개" 찾기 |
| `haunts.py` | `/출 흉가` 결과에서 사람이 있는 흉가 번호 읽기 |
| `minigame.py` | 미니게임 창이 떴는지 보기 |
| `minigame_daemon.py`, `minigame_daemon.sh` | 미니게임 지킴이 (`start.sh`가 같이 켠다) |
| `minigame_pause.sh`, `minigame_solve.py` | 매크로를 세우고 미니게임을 한 번 풀기 |
| `watch.sh`, `reconnect.sh` | 지켜보다 꺼지면 다시 켜기, 첫 화면에서 다시 접속 |
| `config.toml` | 키, 화면 좌표, 사냥 설정 |
| `data/` | 맵 이름 그림, 벽 정보, 출구 목록 |
| `FINDINGS.md` | 시험하며 알아낸 사실과 측정 기록 |
| `MAPS.md` | 맵과 이동 경로 정리 |

`macro.py`, `xy.py` 등 나머지 파일은 이전 Windows용(Tesseract 기반) 매크로입니다.

## 알아 둘 점

- 창 크기가 다르면 `config.toml`의 `[bars]`, `[regions]` 좌표를 고쳐야 합니다.
- 화면 캡처는 호출한 프로세스에 메모리가 쌓여서 일꾼 프로세스에서 찍고 주기적으로 갈아 치웁니다. 자세한 내용은 `FINDINGS.md`에 있습니다.
- 메모리가 부족해 게임이 끊기면 다시 접속해 사냥터까지 돌아가는 것은 수동입니다.
- 체력은 일부러 낮게 둡니다 (`config.toml`의 `heal_to`, `heal_after_refill_to` = 0.15). 공력증강 뒤 나에게 고정해 힐을 연달아 쓰고, 헬파이어는 걷는 중에도 쿨마다 씁니다. 죽으면 성황령으로 부활해 돌아옵니다.
- 미니게임에 실패하면 1분쯤 마법이 안 나갑니다. 풀이는 창 하나에 한 번만 시도합니다.
- 다른 성의 흉가로 건너가는 것(`nav.world_hop`)은 아직 실전에서 돌려 보지 못했습니다.
